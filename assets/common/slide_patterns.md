# 演示文稿页面模式（Slide Patterns）

> 五种标准页面模式，生成时按用途取舍；每种模式都要套用命中的 L2 风格 token。

## 1. 封面页（Cover）

- **要素**：主标题（最大字号）+ 副标题 + 品牌/日期 + 可选背景装饰。
- **风格注入**：用风格强调色做标题或装饰线；深色风格用暗底 + 高光，浅色风格用留白 + 细线。
- **示例**：瑞士极简 → 大标题 + 细分隔线 + 数字序号；赛博朋克 → 霓虹描边标题 + 扫描线背景。

## 2. 目录页（Agenda）

- **要素**：章节列表（编号 + 标题 + 一句话简介）。
- **风格注入**：用风格导航样式（细线/胶囊/色块/霓虹）。
- **示例**：便当拼盒 → 网格卡片目录；粗野主义 → 硬边色块目录。

## 3. 内容页（Content）

- **要素**：章节标题 + 正文要点（分栏/卡片/列表）。
- **风格注入**：用风格卡片样式承载要点。
- **示例**：磨砂玻璃 → 半透明毛玻璃卡片；孟菲斯 → 撞色几何卡片。

## 4. 数据页（Data）

- **要素**：指标卡（大数字 + 标签）+ 图表（条形/环形/热力/趋势）。
- **风格注入**：用风格图表样式（细条栅格/霓虹扫描/仪表盘/马赛克）。
- **示例**：立体超真 → 3D 柱状图；HUD 科幻 → 雷达/数据流。

## 5. 结尾页（Closing）

- **要素**：总结金句 + 联系方式/行动号召（CTA）。
- **风格注入**：呼应封面，形成闭环；CTA 按钮用强调色。

## 通用规则

- **页序**：封面 → 目录 → 内容×N → 数据×M → 结尾，按大纲与内容量取舍。
- **左右翻页**：`<section class="slide">` 分页，`.slide{display:none}` 只显示当前页；键盘 `←`/`→` + 左右箭头按钮 + 触屏滑动三通道切换；默认到边界停住。
- **底部页码与进度**：固定底栏「当前页 N / 总页数 M」+ 进度条（宽 = N/M）+ 可点击圆点跳页（当前页拉长胶囊高亮），随翻页实时更新，强调色填充。
- **一致性**：所有页面共用同一套 `:root` CSS 变量，保证风格统一。

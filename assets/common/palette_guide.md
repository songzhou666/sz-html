# 配色与无障碍指南

## 颜色变量约定

所有风格统一收敛到以下 CSS 变量，风格切换只改 `:root`：

| 变量 | 含义 | 用途 |
| --- | --- | --- |
| `--bg` | 页面背景 | 底色 |
| `--card` | 卡片背景 | 内容容器 |
| `--ink` | 主文字色 | 标题/正文 |
| `--mu` | 次要文字色 | 说明/辅助 |
| `--ac` | 强调色 | 按钮/重点/图表高亮 |
| `--line` | 分割线 | 边框/分隔 |
| `--font` | 字体族 | 全局字体 |

## 对比度要求（WCAG AA）

- **正文文字**：与背景对比度 ≥ 4.5:1。
- **大字标题**（≥24px 或 ≥18.66px 加粗）：≥ 3:1。
- **强调色做文字底**：强调色上放白色文字时，对比度 ≥ 4.5:1，否则加深/降明度。

## 深色/浅色通用建议

| 调性 | 背景 | 文字 | 强调色建议 |
| --- | --- | --- | --- |
| 浅色 | #f5f5f7 ~ #ffffff | #111 ~ #1d1d1f | 中高饱和（#2563eb 等） |
| 深色 | #0a0a12 ~ #1e1e2e | #f5f5fa ~ #fff | 高亮霓虹（#05d9e8 等） |

## 色板提取规则

- L2 风格正文的「配色 Token」表给出该风格权威配色，生成时优先抄用。
- 需要补色时，从该风格「色板」列中选取，保持同色系协调。
- 不得跨风格随意混用色板（除非用户明确要求混搭）。

## 字体栈约定

- **中文无衬线**：`'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif`
- **中文衬线**：`'Noto Serif SC', 'Songti SC', serif`
- **等宽**：`'Sarasa Gothic SC', 'Courier New', monospace`
- **无联网兜底**：不加载 Google Fonts，用系统字体栈；用户明确要求非系统字体时才联网，失败降级系统字体。

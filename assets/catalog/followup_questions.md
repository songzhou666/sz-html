# 大纲 + 选型追问问题库

> S1 内容采集 / S3 选型时按影响度排序取用，一次 ≤4 问，每题带候选选项。

## 1. 内容素材（大纲来源，最高优先级）

- 标题/正文要点/数据/图表/图片是否已备
- **影响**：大纲生成依赖内容；缺素材只能出结构 + 【待补充】占位。

## 2. 用途（影响风格调性）

- 产品发布 / 数据汇报 / 品牌提案 / 融资路演 / 教学培训 / 活动展示
- **影响**：决定偏浅色（投影）还是深色（沉浸）。

## 3. 受众（影响专业度与亲和度）

- 投资人 / 客户 / 领导 / 公众 / 内部团队
- **影响**：投资人→克制专业；公众→亲和易懂。

## 4. 风格偏好（影响族归属）

- 科技感 / 高级感 / 复古 / 自然 / 大胆撞色 / 极简 / 无特别偏好
- **影响**：直接决定候选族（科技霓虹/秩序极简/复古怀旧/有机触感/大胆撞色）。

## 5. 明暗调性（硬过滤）

- 浅色（投影/打印更清晰） / 深色（屏幕/沉浸更有冲击）
- **影响**：L0 硬过滤的第一刀。

## 6. 页数

- 自由输入（如"10 页左右"）
- **影响**：用户指定则优先；未指定由大纲生成时按内容量合理规划。

## 追问句式（大白话 + 候选选项）

```
为了让大纲和风格更准，确认几点：
1. 你手上都有什么内容？（a 标题+正文要点  b 有数据/图表  c 只有主题还没细化  d 其他____）
2. 这份演示用在哪？（a 产品发布  b 数据汇报  c 品牌提案  d 其他____）
3. 给谁看？（a 投资人  b 客户  c 领导  d 公众）
4. 想要什么气质？（a 科技感  b 高级感  c 复古  d 自然  e 大胆撞色）
5. 投屏还是纯屏幕看？（a 浅色投影  b 深色沉浸）
```

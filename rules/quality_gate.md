# 质量审核门禁（五维）

> S6 审核基准 = 命中的 L2 风格正文。自检 + 独立盲审双程。

## 五维审核

| 维度 | 检查点 | 判定 |
| --- | --- | --- |
| 风格还原度 | 配色/字体/圆角/阴影/特效与 L2 正文是否一致 | 偏差大 → BLOCK |
| 排版一致性 | 各页标题层级、间距、对齐是否统一 | 混乱 → BLOCK |
| 响应式 | 1024/640 断点是否生效、窄屏是否可读 | 失效 → BLOCK |
| 可访问性 | 对比度、语义标签、焦点可见、alt | 不达标 → WARN |
| 内容完整性 | 事实准确、无编造、占位符规范 | 编造 → BLOCK |

## 阻断判定

- `BLOCK-风格还原度`：配色/字体/特效与资产明显不符（如赛博朋克做成白底黑字无霓虹）。
- `BLOCK-响应式`：断点失效，窄屏内容溢出/不可读。
- `BLOCK-翻页进度`：左右翻页失效、页码总数错误、进度条与页码不同步。
- `BLOCK-内容`：编造数据/事实/品牌名。
- 阻断必须打回 S5 修复并复审，防"假修复"（只改一处不动其余）。

## 翻页/进度专项（必查）

- 键盘 `←`/`→`、箭头按钮、触屏滑动三通道均可翻页，一次只切一页，边界停住不越界。
- 底部页码「N / M」总数 = 实际页数，随翻页实时更新。
- 进度条宽度 = N/M，翻页时平滑过渡，配色随风格强调色。
- 圆点跳页：圆点数量 = 页数，当前页胶囊高亮；点击任意圆点直达对应页，与页码/进度条同步；页数 >12 时圆点不溢出（缩小或分段）。

## 警告（不阻断，但需在交付说明标注）

- 对比度边缘（正文 4.0–4.5:1）
- 非系统字体未联网加载（已降级）
- 用户要求的风格混搭未标注来源

## 交付清单

交付时附带：

1. **《交付终稿》**：`.html` 文件。
2. **五维结论摘要**：每维 PASS/WARN/BLOCK 一句话。
3. **风格来源说明**：所用风格资产（编号/名称）+ 色板 + 字体。
4. **待补充变量清单**：所有 `【待补充】` 占位汇总。
5. **后续入口**：改某页 / 换风格重做 / 继续优化。

未过 S6 的 HTML 一律不作为终稿交付。

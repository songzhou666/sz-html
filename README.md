## 这是什么

你大概遇到过这些情况：

- 😩 手上有一堆汇报/提案内容，却不想花几小时在 PPT 里拖文本框、调对齐
- 🤔 让大模型直接写 HTML 演示页，配色版式全看运气，改起来无从下手
- 📽️ 想要一份能**直接投屏、左右翻页、带页码进度**的演示，而不是静态长图
- 🎨 想要"高级感/科技感/杂志风"这类气质，却说不清具体该怎么配色、选字体

**sz-html 把做 PPT 的正确姿势搬进了 AI 助手：先出大纲 → 再定风格与页数 → 最后逐页制作 → 交付前五维审核。**
产出一个单文件 `.html`，浏览器双击即开，支持键盘 ←/→ 翻页、左右箭头、手机滑动、底部页码总数与进度条、圆点跳页。

内置 **49 种前端页面风格**（瑞士极简 / 磨砂玻璃 / 赛博朋克 / 复古胶片 / 粗野主义 / 便当拼盒……），
每种风格都带完整的**配色 token、字体字重、圆角阴影特效、组件样式**，风格还原**有据可查**，不靠模型记忆瞎猜。

## 核心能力

| 能力 | 说明 |
|------|------|
| **PPT 式大纲生成** | 先产出章节结构 + 每页标题/要点 + 页数规划 + 页面类型分配，用户确认后才动笔 |
| **49 风格 + 页数双定选型** | 通读全量选型目录 → 结合大纲主题/受众/明暗调性定位 → 输出「风格 + 页数」选型建议卡 |
| **逐页 HTML 生成** | 封面 → 目录 → 内容 → 数据 → 结尾，单文件内联 CSS/JS，零外部依赖 |
| **风格参数注入** | 按命中风格注入完整 CSS 设计 token（配色变量、字体、圆角、阴影、特效）与组件样式 |
| **翻页与进度交互** | 键盘 ←/→ + 左右箭头按钮 + 移动端滑动翻页；底部固定「当前页 N / 总页数 M」+ 进度条 + 圆点跳页 |
| **五维质量审核** | 风格还原度 / 排版一致性 / 响应式 / 可访问性 / 内容完整性，阻断项打回重做 |
| **修订与换风格** | 交付后"改第 3 页""换个配色"不重走选型，保留画像与风格直接修订 |
| **风格混搭** | 用户明确要求时允许跨风格借用组件（如玻璃卡片 + 极简排版），交付说明标注来源 |

## 快速开始

直接把需求说清楚即可，三种典型开场：

```text
帮我做一份面向投资人的产品发布会 HTML 演示，风格要科技感、沉浸式。
```

```text
做一份企业年终数据汇报的网页版 PPT，10 页左右，浅色风格，适合投影。
```

```text
给我一份品牌提案的 HTML 演示，要有高级感、杂志风。
```

**它会依次给你三个可确认的产物**：

1. 📋 **演示大纲（草案）** —— 章节结构 + 每页要点 + 页数规划，你说"按此继续"或调整
2. 🎨 **风格选型建议卡** —— 推荐风格 + 理由 + 备选 + 页数拆分，你拍板或改选
3. 📄 **HTML 演示文稿** —— 单文件 `.html`，附五维审核结论与风格来源说明

一条完整流程：

```text
S0 意图识别 → S1 内容采集 → S2 大纲生成 → S3 风格+页数选型 → S4 用户确认
          → S5 生成 HTML（左右翻页 + 底部进度）→ S6 五维质量审核 → 交付终稿
```

## 适用场景 vs 不适用场景

| ✅ 适用 | ❌ 不适用 |
|---------|----------|
| 产品发布会 / 融资路演 / 品牌提案 / 数据汇报 / 教学培训的 HTML 演示 | 生成 Word / PPT **原生文件**（`.docx` / `.pptx`）→ 用 Office 文档类技能 |
| 已有 HTML 演示想"换个风格重做" | 微信小程序 / 需后端服务的完整应用 |
| 演示稿"改第 X 页""优化排版" | 修改已有 HTML 的功能 bug（表单/接口逻辑）→ 通用编程 |
| 想要"科技感/高级感/杂志风"等气质型演示 | 纯知识问答（"HTML 是什么"）|

**资产三级渐进式加载**（省 token、不靠记忆）：

| 级 | 时机 | 读取对象 | 作用 |
| --- | --- | --- | --- |
| L0·选型 | 选型起，常驻 | `assets/catalog/catalog_l0.md` | 49 风格全景 + 7 族总览，按明暗调性硬过滤 |
| L1·按族 | 锁定候选族后 | `assets/index/{族}.md` | 精确到唯一风格，多风格命中交用户选 |

## 安装

**方式一：git clone**

```bash
git clone https://github.com/songzhou666/sz-html.git
```

把得到的 `sz-html/` 目录放进 IDE 的技能目录即可（如项目级 `.trae/skills/sz-html`，或用户级技能目录）。

**方式二：下载 zip**

下载仓库 zip 解压，把 `sz-html/` 放进技能目录。也可本地执行 `python build.py` 生成 `sz-html-skill.zip` 分发。

> 技能为**纯提示词 + 本地资产**驱动，不依赖 CLI 工具与外部 API；仅当你要求非系统字体（如 Google Fonts）时才需联网，且会降级系统字体兜底。
